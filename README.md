# RivexMeteor

RivexMeteor is a lightweight Minecraft plugin designed for Paper 26.2, built using Java 25. It creates a dynamic and engaging gameplay experience by randomly spawning meteors that fall at intervals configurable in YAML. Each meteor impact generates a visible effect with particles, sounds, and a crater-free landing, spawning a loot chest filled with randomized configurable rewards, including money, custom items, and ExcellentCrates keys. The plugin broadcasts meteor announcements to all players, offers configurable loot chances, cooldowns, admin commands, permissions, and persistent data, ensuring it is optimized, easy to configure, and compatible with Vault.

## Install

1. Download the latest version of RivexMeteor from the [GitHub repository](https://github.com/EnderDevelopment/RivexMeteor).
2. Place the downloaded JAR file into the `plugins` folder of your Paper server.
3. Start or restart your server to load the plugin.

## Use

1. Ensure the plugin is installed and the server is running.
2. Configure the plugin settings in the `config.yml` file located in the `plugins/RivexMeteor` folder.
3. Use the following commands to manage the plugin:
   - `/rivemeteor reload` - Reload the configuration file.
   - `/rivemeteor start` - Start the meteor task.
   - `/rivemeteor stop` - Stop the meteor task.
